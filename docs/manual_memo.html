메모

각 마디마다 Markdown 메모를 작성할 수 있습니다. 편집 영역 오른쪽에서 Markdown 미리보기를 확인할 수 있습니다.

  • Ctrl+S: 메모 저장
  • Ctrl+L: 메모 불러오기
  • File 메뉴: 메모 저장, 메모 다른이름으로 저장, 메모 불러오기

기본 저장 파일은 원본 탭 파일과 같은 폴더의 memo_원본파일명.mmdx입니다. .mmdx는 ZIP 기반 형식이며, 마디별로 M1.md, M25.md처럼 파일이 분리됩니다.

Markdown 이미지가 로컬 파일을 참조하면 저장할 때 해당 이미지가 .mmdx 안에 함께 포함됩니다.

메모 입력 중에는 전체 악보 표시 갱신을 5초 단위로 제한해 입력 지연을 줄입니다. 자동저장은 10초마다 실행됩니다.
