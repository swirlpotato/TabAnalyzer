Tab Analyzer Manual

Use this guide from top to bottom the first time you run Tab Analyzer. It follows the same order as the app: open a Guitar Pro file, inspect analysis, play the tab, save notes, record practice, and use the tuner.

1. Open And Close Files 2. Read The Screen 3. Follow Measure Analysis 4. Use The Tab Player 5. Scale And Chord Views 6. Write Memos 7. Record Practice 8. Chromatic Tuner

1. Open And Close Files

  1. Choose File > Open, then select a .gp, .gp3, .gp4, .gp5, or .gpx file.
  2. Use the Track combo box when the file has multiple guitar tracks.
  3. Use Tuning to keep the file tuning or preview another built-in tuning.
  4. Open a previous song from File > Recent files.
  5. Choose File > Close file to return the app to the initial no-file state.
  6. Choose File > Exit to quit the app.

If a memo has unsaved changes, Tab Analyzer asks whether to save before opening, closing, or exiting.

2. Read The Screen

  1. The top toolbar contains file actions, Songsterr search, zoom, track selection, and tuning selection.
  2. The upper-left area has Analysis measures and Tab player tabs.
  3. The lower-left tabs show the selected measure on the fretboard, scale view, song scale view, measure notes, and memo editor.
  4. The right panel shows whole-song analysis, chord positions, chord finder, and recording tools.

3. Follow Measure Analysis

  1. Click a measure to focus it. The fretboard and explanation panes update together.
  2. Click a scale or chord chip inside a measure to see why that candidate was selected.
  3. Use the lower Measure notes tab to read scale evidence, chord evidence, and function interpretation.
  4. When a chord chip is selected, the right panel switches to Chord positions and shows playable shapes.
  5. Use Zoom or hold Ctrl and scroll to resize the analysis view.

4. Use The Tab Player

  1. Open the Tab player tab.
  2. Select one or more measures by dragging across the score.
  3. Press Play to start playback. If MIDI output is unavailable, the cursor still moves so you can follow the score.
  4. Set Repeat selection to loop the selected measures.
  5. Adjust Speed for slow practice.
  6. If the Songsterr file has YouTube metadata, use the YouTube controls and Sync offset to align playback.

6. Write Memos

  1. Select a measure, then open the lower Memo tab.
  2. Write notes in Markdown. Use this for practice comments, fingerings, or lesson notes.
  3. Choose File > Save memo or press Ctrl+S.
  4. Use Save memo as to create a separate .mmdx memo package.
  5. Use Load memo to attach an existing memo package to the current tab.

7. Record Practice

  1. Open the right-side Recording tab.
  2. Select the microphone or audio interface from Input.
  3. Set BPM and Beats. Enable Record click if you want the metronome mixed into the saved file.
  4. Press F10 or the record button to record.
  5. Press F11 to stop.
  6. Press F12 to play the last recording, or use the list to play/delete older recordings.

8. Chromatic Tuner

  1. Choose Additional Features > Chromatic tuner.
  2. Select the input device. Use Refresh if you plugged in an audio interface after opening the window.
  3. Set Reference A4. Standard tuning uses 440.0 Hz.
  4. Choose Single string to tune one string at a time. Select a tuning preset, leave Target string on auto or choose the exact string, then tune until the meter is centered and the status says In tune.
  5. Choose All strings, then select the tuning preset such as Standard, Drop D, D Standard, DADGAD, or Open G.
  6. Strum all open strings and read each row from the lowest string to the highest string.
  7. If a string signal drops out briefly, the last stable position stays visible for a moment as Last signal.
  8. Mute unused strings and keep the input level clean. A noisy room, clipping, or heavy effects can reduce detection stability.
